tessera: offline pipeline

Nothing is sent anywhere. All processing happens in your browser. Your save files never leave this machine.

Heavy local processing: a save can weigh several tens of MB once decompressed. Expect a few seconds on recent PC or Mac; the page remains usable while computing (runs in the background).

This is the vendored copy of the recipe, served from 127.0.0.1 by tessera serve. It runs the same code as the site. There is no ingestion endpoint here: if you tick "Share the geography" or "Add to the public mosaic" and continue, the upload is attempted and answered with an explicit 501, which is visible in the network tab and in the status line under Payload A for the geography, under the seed for the mosaic tile. Those two are the only calls this page makes.
